# 宝くじデータ分析アプリ

ナンバーズ、ロト6、ロト7、ミニロトの過去データを保存・管理し、最適な値を抽出するためのアプリケーションです。

## 特徴

- **大量データ対応**: SQLiteを使用し、数万〜数十万件のデータを効率的に管理
- **データ分析**: 出現頻度、ペア分析、推奨数字の抽出
- **直感的なUI**: Streamlitによる使いやすいWebインターフェース
- **データインポート**: CSVファイルからの一括インポート対応

## 対応している宝くじ

- **ナンバーズ**: 4桁の数字（0000-9999）
- **ロト6**: 1-43から6個の数字
- **ロト7**: 1-37から7個の数字
- **ミニロト**: 1-31から5個の数字

## セットアップ

### 必要な環境

- Python 3.8以上

### インストール

1. リポジトリをクローンまたはダウンロード

2. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### アプリケーションの起動

```bash
streamlit run app.py
```

ブラウザが自動的に開き、アプリケーションが表示されます。

### サーバーの停止

#### 方法1: ターミナルで停止
ターミナルで `Ctrl + C` を押す

#### 方法2: バッチファイルを使用（Windows）
```bash
stop_server.bat
```

#### 方法3: PowerShellスクリプトを使用（Windows）
```powershell
.\stop_server.ps1
```

## 過去データの入手方法

過去データを入手する方法については、**`DATA_SOURCES.md`** ファイルを参照してください。

主な入手先：
- 公式サイト（各都道府県の財務局）
- 宝くじ情報提供サイト
- 銀行のオンラインサービス

## 使い方

### 1. データ登録

#### 手動登録
- 「データ登録」ページで、抽選日、抽選回数、当選番号を入力して登録

#### CSVインポート
- CSVファイルを準備し、「CSVインポート」タブからアップロード

**CSV形式の例:**

ナンバーズ:
```csv
draw_date,draw_number,winning_number
2024-01-01,1,1234
2024-01-02,2,5678
```

ロト6/ロト7/ミニロト:
```csv
draw_date,draw_number,numbers,bonus_number
2024-01-01,1,"[1,2,3,4,5,6]",7
2024-01-08,2,"[10,15,20,25,30,35]",40
```

### 2. データ分析

「データ分析」ページで以下の分析が可能です：

- **出現頻度**: 各数字の出現回数を分析
- **推奨数字**: 出現頻度の高い/低い数字を抽出
- **ペア分析**: よく一緒に出現する数字のペアを分析
- **詳細分析**: ホット/コールドナンバーの詳細情報

### 3. 統計情報

「統計情報」ページで、各宝くじのデータベース統計を確認できます。

### 4. データ検索

「データ検索」ページで、日付範囲を指定してデータを検索・表示できます。

## データベース構造

### numbers テーブル
- `id`: 主キー
- `draw_date`: 抽選日
- `draw_number`: 抽選回数
- `winning_number`: 当選番号（4桁）
- `created_at`: 作成日時

### loto6 テーブル
- `id`: 主キー
- `draw_date`: 抽選日
- `draw_number`: 抽選回数
- `numbers`: 当選番号（JSON形式、6個）
- `bonus_number`: ボーナス番号
- `created_at`: 作成日時

### loto7 テーブル
- `id`: 主キー
- `draw_date`: 抽選日
- `draw_number`: 抽選回数
- `numbers`: 当選番号（JSON形式、7個）
- `bonus_number`: ボーナス番号
- `created_at`: 作成日時

### miniloto テーブル
- `id`: 主キー
- `draw_date`: 抽選日
- `draw_number`: 抽選回数
- `numbers`: 当選番号（JSON形式、5個）
- `bonus_number`: ボーナス番号
- `created_at`: 作成日時

## 注意事項

- データベースファイル（`lottery_data.db`）は自動的に作成されます
- 重複データは自動的にスキップされます（`draw_date`と`draw_number`の組み合わせでユニーク制約）
- 大量データを扱う場合、検索や分析に時間がかかる場合があります
